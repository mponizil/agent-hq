# discussions/

Each `.md` file added here is posted to the repo's Discussions when it merges to `main` (see
`.github/workflows/post-discussions.yml`). Frontmatter: `category` (Changelog, Ideas or Questions) and
`title`, or `reply_to: <discussion number>` for a reply. Follow [CHANNEL.md](../CHANNEL.md): generic
platform talk only, and when in doubt, don't post.
